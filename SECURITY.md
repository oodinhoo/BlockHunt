# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/oodinhoo/BlockHunt/security/advisories/new)
(Security tab → *Report a vulnerability*), with the steps to reproduce and the Paper version used.

Once fixed, the issue is disclosed in a GitHub security advisory and in the release notes.
